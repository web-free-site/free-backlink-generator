How to submit a sitemap to Google Search Console

A sitemap is a list of URLs you want crawlers to know about. Submitting it in Google Search Console does not guarantee indexing, but it is a standard way to help Google discover pages. This guide is general; Google's screens can change, so follow the labels you see in your account.

Steps

  1. Confirm the sitemap URL. On your site, open /sitemap.xml (or the sitemap index your platform publishes) and check that it returns an XML file and that the URLs are correct.
  2. Open Search Console for the property. Use the Search Console property that covers the domain or URL prefix. You must already have access.
  3. Add the sitemap. Find the sitemaps section, enter the sitemap path or full URL as the interface requests, and submit it.
  4. Wait and read the status. Processing can take time. A success state means the file was read, not that every URL is indexed. Use the URL inspection tools when you need to request a specific page.

Bing and others

Other search engines have their own webmaster tools. A sitemap can often be reused, but each service has its own submission form or API.
